# Connected initial Knife PAN regression

Run `python build/test_pencil_knife_initial_pan.py`. The default reconstructs the
authoritative overlay from its fixed Blender pin and explicit source inventory.
`--source-root` accepts an existing materialization for development; the final
gate must also pass without that option. Every compile/run result, source body
and runtime dependency hash is recorded in the selected output directory.

The new family extends the retained raw-map/invoke model and replaces only its
three explicitly inactive Knife adapters with actual source. It executes native
Knife and Zoom registration, initial Knife invocation and original-owner bind,
the complete generated Knife modal-map native import/copy, exact Ctrl/raw-PAN
modal processing and status, fresh strict owner/type/mode/modal-map checks,
actually chosen native keymap dispatch, full invocation, real native poll and
refusal before operator or navigation allocation. Both generated View3D profiles
are evaluated; only their three PAN entries are instantiated in the native map.

Controls execute real Zoom distance changes, actual mixed-source queue clearing,
custom modal keyboard/PAN delegation including PANNING mode reset, current and
stale emulated-MMB state, custom chosen operators, owner/profile invalidations,
native view locks and preserved native/hardware/multi-finger invocation paths.
The old verified `3d7b248` full invocation body has a fixed provenance/body hash;
its required-denial controls must fail at O0 and O2 with actual allocation and
distance change. Only function definition names and the disclosed signature
adapter differ from that frozen native body.

Native-shaped backing objects (including an integer Knife mode field exercised
only with declared native enum values), scalar RNA/schema emission, registries, allocator,
context providers, initial edit-mesh poll, geometry/setup and ViewOpsData navigation
initialization are instrumented boundaries. Move/Rotate geometry application is
counted, not reimplemented. The complete modal WM scheduler, UIKit producer,
geometry/history/Undo and Cancel rollback are not certified by this family. The
retained producer/transport suites cover physical classification separately. No
accepted physical DOWN, general lease, native ABI, SDK build or device claim is
made. Production algorithms are never repaired or autocorrected by the fixture.
