# Pencil ring delivery contract

The latest human direction is authoritative. This contract adds an independent review before delivery; the human should not be the first person to notice a mismatch with their instructions.

## Current requested design

Base has exactly nine clockwise positions from the top: **Layout / Mode, More Tools, Undo, Redo, Select, Move, Rotate, Scale, Cursor**. Select and the four other native tool choices act directly. View and Selection category menus are absent. Base and More Tools use the same native Tools radius, button sizes, dark/blue styling, icon handling, readable labels and empty center. No compact Base variant remains.

More Tools contains only the remaining compatible native tools. Exclude the exact IDs `builtin.select_box`, `builtin.move`, `builtin.rotate`, `builtin.scale`, `builtin.cursor`; retain Tweak/Lasso/Circle, Transform, Add Cube, Annotate, Measure and every other compatible modeling/sculpt/paint tool. Do not append a utility/navigation page or count unrelated actions as extra tools. Native header/left Settings provide advanced access; Pencil-barrel Home returns from the category.

Keep all nine positions in modes lacking a requested tool, visibly disabled and guarded against dispatch. Do not silently substitute a brush or mask for Select. Preserve accepted contact-only circular browsing, persistent admitted choices, Pencil-barrel Home/context, outside/repeat-squeeze dismissal, collapsed lower-left future controls, native Redo/Cancel/one-step Undo, full Blender bars, Inspector/editors/splits/Files/hardware and launch correction.

## Independent pre-delivery review

1. Write a literal acceptance list from the latest human direction before implementation. Reconcile older design notes with it; do not add categories by inference.
2. An independent reviewer checks the final source, actual native widget evidence, counts, exact icon/tool IDs, selected/disabled states, full inventories and geometry against that list. A separate correctness review checks native dispatch/lifetime/contact/history seams when they are affected. Resolve findings before native build.
3. Use connected source/host checks to catch mismatches: exact nine Base identities, no duplicate primary tools in More Tools, all native variants retained, equal Base/Tools targets and footprints across DPI/window fits, actual overflow count, label fitting, preserved native header and guarded unavailable actions.
4. Inspect actual native host visuals before delivery. State their limits: stock widget grids do not prove patched circular layout/GPU/touch. Record source, host, package and device evidence separately. Do not ask the user to design routine placement or retest unchanged source.
5. Build a coherent exact source revision once, fix actual errors, and verify the downloaded whole IPA. Deliver with a concise description of the visible change and any material unverified behavior. Never treat passing packaging as user acceptance.

The current independent UX review caught utility actions leaking into More Tools; that tail was removed before build. Reviews and native evidence live in output/ui-preview/pencil-nine-base. The full personal Pencil-first goal remains unfinished.
