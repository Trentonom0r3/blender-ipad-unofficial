# Personal Pencil-first Blender: end-state concept

The user requested a visualization of the completed app and full Pencil workflows. This concept describes the intended personal workflow, not the current build or target-device proof. It is deliberately inspectable and interactive; it is not a generated product screenshot.

## Established design to preserve

- Blender's native menu/viewport bars, editors and current Inspector remain recognizable.
- Squeeze opens exactly Layout/Mode, More Tools, Undo, Redo, Select, Move, Rotate, Scale, Cursor. Native tool icons and common Tools geometry/style remain; empty radial center.
- Compatible native inventories roll through nine visible positions. Hover does not browse; contact-circle browses without activating. Pencil-barrel double-tap returns Home/Base; outside/repeat squeeze closes.
- Ordinary choices stay open through fresh native reconstruction. Advanced children/modal tools own their lifecycle.
- Future controls are small collapsed lower-left panels. Native last-operation Redo remains separate, with coherent Cancel and one-step Undo.
- Side editors/Inspector retain familiar category access, controllable width, native values and splits. Hardware remains supported even though this personal workflow needs no trackpad or physical keyboard.

## Full session targets

1. Choose a mode/tool at the Pencil, keeping the canvas visible.
2. Model with native selection, Move/Rotate/Scale, Extrude/Bevel and complete compatible tool inventories.
3. Set the next stroke's axis/orientation/pivot/precision/snap, then adjust the accepted edit through native Redo. Finish values through touch/on-screen input; Scribble is an eventual target requiring validation.
4. Sculpt using dependable pressure/tilt/brush access, keeping finger navigation from painting/changing tools. Brush assets remain distinct from native tool inventory.
5. Use Inspector, modifiers, materials, native node sockets/wires and editors comfortably with Pencil.
6. Scrub/keyframe in native Timeline and animation editors with precise values/history.
7. Render, save/reopen through Files with assets, recovery and interruption handling.

These targets do not claim all desktop features are already available or accepted without hardware input. Current priority remains perceptible Pencil interaction and confirmed regressions; import/deep-camera expansion stays deferred.
